# Anti-Defensive Writing

- 项目：<https://github.com/Kiterlin/anti-defensive-writing>
- GitHub Star：1,331（快照日期：2026-10-23；Star 会持续变化）
- 许可证：MIT
- 形态：Codex Skill
- 主要定位：让学术、技术和专业写作更直接、清楚、简洁，同时保留必要的证据边界

## 核心能力

该 Skill 识别并修改不必要的防御性表达，包括道歉式开场、重复免责声明、过度保留词、消极自我限定和与任务无关的长篇解释。它尤其适合论文摘要、引言、贡献陈述、讨论、结论、审稿回复和技术报告的最后一轮文字校准。

它不会把谨慎写作改成夸大写作。方法限制、统计不确定性、伦理约束、样本范围、观察性研究的非因果边界以及真正影响结论的限定都应保留。

## 在 Codex 中调用

安装后可直接调用：

```text
$anti-defensive-writing

请修改论文讨论部分：
1. 删除道歉式表达和重复限定；
2. 用正面的研究范围陈述替代“本文不试图……”；
3. 保留因果识别、样本范围和测量误差限制；
4. 不新增事实、引用或贡献；
5. 输出修改稿和关键修改说明。
```

## 推荐使用阶段

在研究内容、结果、引用和论证结构已经基本确定后使用。若过早调用，流畅的文字可能掩盖尚未解决的证据问题。

## 风险与边界

- 不用于文献检索、事实核验或统计分析；
- 不应删除会改变结论可信度的方法限制；
- 不应把相关性改写为因果关系；
- 修改后仍需作者逐句确认语义和学术责任。
