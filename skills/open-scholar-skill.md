# Open Scholar Skill

- 项目：<https://github.com/joshzyj/open-scholar-skill>
- GitHub Star：177（快照日期：2026-10-23；Star 会持续变化）

- 形态：面向社会科学研究的 Claude Code / Codex Markdown Skills
- 主要定位：从研究构思、文献综合到投稿准备的学术工作流

## 为什么值得关注

Open Scholar Skill 针对社会科学与期刊论文场景，覆盖研究问题、理论机制、文献综述、实证策略、写作、核验、投稿和研究伦理。Skill 以普通 Markdown 目录提供，可被 Codex 读取；项目还特别强调引用核验、AI 使用披露、数据安全和研究者责任。

## 适合的任务

- 收敛研究问题并检查理论贡献；
- 梳理社会科学文献和理论机制；
- 规划定量、定性或混合方法研究；
- 检查引文是否真实存在、是否支持对应论断；
- 按期刊风格准备稿件与投稿材料；
- 生成 AI 使用披露草稿；
- 在投稿前执行结构化的完整性检查。

具体 Skill 名称和开放范围可能随版本变化，应查看仓库当前目录。项目说明明确指出，开源版本不包含某些完整论文、基金、教学、书籍和演示编排器，因此不要假设仓库覆盖其产品或作者提到的所有能力。

## 在 Codex 中安装

克隆后，审查需要的 Skill，并链接或复制到 Codex Skills 目录：

```bash
git clone https://github.com/joshzyj/open-scholar-skill.git
```

项目说明支持把普通 Markdown Skill 链接到 `~/.codex/skills`，然后以自然语言调用，例如：

```text
使用 scholar-idea，帮我把这个宽泛的社会科学主题收敛成可回答的研究问题。
只提出问题和候选机制，暂时不要写论文正文。
```

安装其数据安全 hook 前应先阅读 hook 的实际行为、目标路径和宿主兼容性，不应仅因项目支持 Codex 就自动执行安装脚本。

## 风险与边界

- 社会科学研究中的理论选择、因果识别和作者决策不能交给 Skill 自动决定；
- 自动引用核验不能替代阅读全文和检查引用语境；
- AI 使用披露需以目标期刊当前政策和实际使用记录为准；
- 数据安全 hook 会改变项目行为，启用前应代码审查并固定版本。
